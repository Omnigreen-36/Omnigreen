Option 1 : Batterie + panneaux

Batterie 7.4 V 2000mAh / jusqu'à 12V
DC/DC 12V -> 5V
Régulateur MPPT ou PWM
Panneau 30cm*35cm 30W 18V

Branchements avec un breadboard
🔴 + ─────────────────────
⚫ GND ────────────────────
1- Brancher la batterie
2- Brancher les deux L298N
3- Brancher le DC/DC
IN+ → rail rouge
IN- → rail GND
OUT+ → Arduino 5V
OUT- → Arduino GND
4- GND Arduino --> GND breadboard
5- Panneau
Brancher le panneau à la batterie via un régulateur
PANNEAU → RÉGULATEUR → BATTERIE → ROBOT

Panneau -> Régulateur
Panneau + → PV+
Panneau - → PV-
Régulateur -> Batterie
BAT+ → Batterie +
BAT- → Batterie -
Batterie -> breadboard
